# Depth First Search

A Java program to traverse a graph using Depth First Search (DFS).

## Features

- Creates an undirected graph
- Takes a starting vertex
- Traverses the graph using DFS
- Displays the DFS traversal

## Technologies Used

- Java
- ArrayList
- Scanner

## Concepts Used

- Graph
- DFS
- Recursion
- Adjacency List
- Visited array

## Output

DFS Traversal: 0 1 3 4 2
